# Product

Product is how a startup turns a problem into something people can use — and eventually pay for.

This section covers how founders define the first version of a product, choose a sharp entry point, find product-market fit, and design products that can grow.

## Learning path

1. [MVP](mvp.md) — ship the smallest useful version
2. [Wedge](wedge.md) — pick a narrow entry point
3. [Founder-Market Fit](founder-market-fit.md) — why *you* can win this market
4. [Product-Market Fit](product-market-fit.md) — evidence that the market wants the product
5. [Product Worth](product-worth.md) — value created and willingness to pay
6. [Product-Led Growth](product-led-growth.md) — when the product drives acquisition and expansion
