# Resources

Curated starting points for deeper learning. Prefer primary sources and reputable operators. This list is not exhaustive and will grow through contributions.

## Classic essays & libraries

- [Paul Graham Essays](https://www.paulgraham.com/articles.html) — ideas, growth, default alive/dead, startup psychology
- [Y Combinator Library](https://www.ycombinator.com/library) — practical founder guidance
- [Y Combinator SAFE documents](https://www.ycombinator.com/documents) — SAFE primaries

## Funds & platforms (educational)

- [a16z](https://a16z.com/) — market, GTM, and technical company-building essays
- [Sequoia Arc / articles](https://www.sequoiacap.com/) — company-building perspectives
- [First Round Review](https://review.firstround.com/) — operator interviews and tactical essays
- [OpenView](https://openviewpartners.com/) — product-led growth research and SaaS topics
- [Stripe Press](https://press.stripe.com/) / Stripe Atlas guides — company building and economics

## Books (selected)

- Eric Ries — *The Lean Startup*
- Geoffrey Moore — *Crossing the Chasm*
- April Dunford — *Obviously Awesome* (positioning)
- Hamilton Helmer — *7 Powers* (strategy/moats)
- Peter Kazanjy — *Founding Sales*
- Bill Aulet — *Disciplined Entrepreneurship*
- Madhavan Ramanujam — *Monetizing Innovation*

## Metrics & finance education

- Bessemer Cloud / SaaS metrics discussions
- ChartMogul, ProfitWell, and similar SaaS metric education centers (verify definitions against your finance policy)
- Startup CFO / operator blogs on cash, runway, and unit economics

## How to use these sources here

When contributing to this repo:

1. Summarize in original wording
2. Link the source in “Further reading”
3. Prefer durable links when possible
4. Do not paste copyrighted chapters or paywalled articles

See [CONTRIBUTING.md](../CONTRIBUTING.md).
