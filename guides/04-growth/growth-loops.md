# Growth Loops

> A growth loop is a closed system where the output of one cycle becomes the input of the next, creating compounding growth.

## What it means

Instead of a linear funnel that ends (“ad → signup → done”), a growth loop returns energy to the top:

```text
New user → takes an action → creates artifact/invite/content/revenue signal → attracts more users
```

Examples:

- user invites teammates to collaborate
- user publishes a page that ranks and brings more users
- marketplace transaction improves trust, bringing more supply/demand
- paid customer funds more acquisition which creates more customers

Loops can be organic, paid, sales-driven, or hybrid. The key is compounding structure.

## Why it matters

Funnels leak. Loops can compound.

Companies that understand their loops invest in the constraints of the loop (activation, invite rate, content quality) rather than random tactics.

This framing is widely associated with modern growth practice (including Reforge-style teaching).

## When founders should care

- Once you have a product people return to
- When planning roadmap bets that should grow the business, not only delight
- When diagnosing growth stalls (“which step in the loop broke?”)
- When choosing between channel tactics vs system design

## How it works

Document each loop with:

1. Input
2. Action
3. Output
4. Reinvestment mechanism
5. Constraint metric

### Example: collaboration loop

| Step | Metric |
| --- | --- |
| Signup | signups |
| Create workspace | activation rate |
| Invite teammates | invites per activated user |
| Invited user joins | invite accept rate |
| New users repeat | cycle time |

### Example: content loop

Users create public templates → templates rank/share → new users arrive → more templates.

## Practical example

A Notion-like startup notices teams grow when templates are public.

Product bet: make “publish template” easy and SEO-friendly.

Loop math sketch:

- 1,000 activated users/month
- 10% publish a template
- each template brings 3 signups over 90 days
- 100 × 3 = 300 new signups attributable to loop

Improve publish rate to 15% and template quality → loop output scales without linear ad spend.

## Common confusion

| Term | Difference |
| --- | --- |
| [Flywheel](flywheels.md) | Broader strategic compounding narrative; loops are operational mechanisms |
| [Viral loop](viral-loops.md) | A loop powered specifically by user-driven invites/shares |
| Funnel | Linear stages; may feed a loop but is not itself a loop |
| Growth hack | One-off tactic; loop is a repeating system |
