# Dilution

> Dilution is the reduction in ownership percentage that existing shareholders experience when new shares are issued.

## What it means

If you own 40% and the company issues new shares for investors (or a larger option pool), your percentage falls — even if the company’s value rises.

Simplified priced-round example:

- Founders own 80%, employees pool 20% (illustrative)
- Raise $5M at $20M pre / $25M post
- New investors own 20% post-money
- Everyone else’s ownership scales down proportionally (before pool reshuffles)

**Ownership % can fall while personal stake value rises** if valuation increases enough. Dilution is about percentage; wealth depends on value × percentage.

## Why it matters

Founders who ignore dilution stacks (SAFEs + pool increases + multiple rounds) can end up under-motivated or under-powered. Employees also feel dilution via option pool refreshes.

## When founders should care

- Before accepting any financing
- When increasing the option pool
- When issuing many SAFEs
- When comparing term sheets

## How it works

### Model scenarios

Build a simple [cap table](cap-table.md) model:

1. current ownership
2. SAFE conversions
3. option pool adjustment (who dilutes?)
4. new money ownership
5. post-round ownership

### Option pool shuffle

Term sheets often require an option pool “top-up” calculated on a pre-money basis, which can disproportionately dilute founders. Read carefully.

## Practical example

Founder owns 60% pre-round.

- Round sells 20% to new investors
- Pool top-up takes another ~10% effectively from existing holders (illustrative)

Founder may land near ~40%+ depending on structure — still potentially great if the company value jumped. The point is to calculate, not guess.

## Common confusion

| Myth | Reality |
| --- | --- |
| “Dilution is always bad” | Percentage down can be wealth up |
| “Valuation is all that matters” | Pool terms and liquidation prefs matter too |
| “SAFEs don’t dilute” | They dilute at conversion |
