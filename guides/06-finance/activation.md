# Activation

> Activation is the moment (or short path) when a new user first experiences real value — the “aha” that predicts later retention.

## What it means

Signups are not activated users. Activation is the early behavior that correlates with sticking around.

Examples:

- creating first project + inviting a teammate within 24 hours
- connecting a data source and generating first insight
- sending first invoice
- completing first successful workflow run

Good activation definitions are specific, measurable, and predictive of retention — not vanity checklist completions.

## Why it matters

Activation is often the highest-leverage growth lever. Improving activation can improve retention, [CAC](cac.md) efficiency, and viral invite rates simultaneously.

Many “growth problems” are activation problems in disguise.

## When founders should care

- As soon as onboarding exists
- When signup volume is fine but retention is weak
- In [PLG](../01-product/product-led-growth.md) design
- When defining [North Star](../04-growth/north-star-metric.md) input metrics

## How it works

Process:

1. Analyze retained users’ early actions
2. Hypothesize an activation event/path
3. Validate that activated users retain much better
4. Redesign onboarding to get more users there faster
5. Remove steps that do not support activation

### Time-to-value

Faster activation usually beats prettier onboarding tours. Measure median time to activation event.

## Practical example

Analytics startup:

- old activation: “completed setup wizard”
- wizard completion did not predict retention
- new activation: “connected production data + saved first dashboard viewed by 2+ teammates”
- that event predicts 3× higher week-8 retention

Onboarding is rebuilt around getting to that event, even if fewer vanity setup steps are completed.

## Common confusion

| Term | Difference |
| --- | --- |
| Signup | Account created |
| Conversion | Often means purchase; activation can be pre-pay |
| Retention | Longer-term continuation |
| Feature adoption | May be later expansion, not first aha |
